# FlipFrame
A React website built to help the user figure out the optimal prices for their items

## Setup
1. Clone the repository.
2. Install dependencies in both frontend/flipframe and backend using 'npm install'
3. Ensure the .env file has the correct variables
4. Use both the setup files using 'node createLookupFile' and 'node getJWT'
5. Go to the frontend/flipframe directory and 'npm run dev:all'


## Purpose
Built to help me learn how to build frontend and backend projects, mainly to learn how React works and interacts with a backend API
